# Zehn

A free engine-sound simulator for the browser. 17 cars, from the Audi R8 V10 to a Tesla Model S Plaid with the Track Package, each with its own live-synthesized sound, gearbox and dash.

Open it: https://thetorchicken.github.io/zehn/

- **Simulator:** drive with the keyboard (W gas, S brake, E/Q shift, Enter start) or the on-screen pedals and paddles.
- **GPS drive:** in a car, the sound follows your real speed. Steering-wheel media buttons shift gears where the browser supports it.

Every sound is synthesized live in the browser; nothing is recorded. Not affiliated with any carmaker.
